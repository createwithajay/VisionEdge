# VisionEdge Distributed Stream Processor
This repository contains the backend and streaming infrastructure for the VisionEdge project.

## API Endpoints (Member 4 - WebRTC & Backend)
- **POST /offer**: Handles WebRTC SDP handshake and streams video[cite: 3].
- **POST /upload_model**: Uploads TensorRT .engine files for on-the-fly model swapping[cite: 3].
